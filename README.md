# CONDENA

Videojuego mobile Android de combate 2D y narrativa manga ambientado en una cárcel chilena ficticia.

Motor objetivo: Godot 4.x. Pantalla horizontal 1280×720 (16:9). Estado: prototipo inicial, no APK funcional todavía.

## Objetivo de fase 1
- Primer combate táctil: Hacker vs El Chico
- Narrativa del capítulo 1 «El Pollo» con decisiones y consecuencias
- Arte manga seinen original, con continuidad entre viñetas y combate
- Progresión y ranked (año 5) en fases posteriores

## Monetización futura
Solo anuncios recompensados voluntarios y compras opcionales de aceleración, sin poder exclusivo de pago.
